
# 📊 Excel Data Analysis Project

## 📌 Project Overview

This project focuses on analyzing and interpreting data using Microsoft Excel. It demonstrates practical Excel skills, including data cleaning, formula-based calculations, Pivot Tables, and interactive charts to generate meaningful business insights.

The objective is to transform raw data into structured information that supports effective data analysis and decision-making.

## 🎯 Project Objectives

- Clean and organize raw datasets.
- Analyze data trends and patterns.
- Perform calculations using Excel formulas.
- Summarize data using Pivot Tables.
- Create charts and dashboards for data visualization.
- Generate meaningful insights to support business decisions.

## 🛠️ Tools & Features Used

| Tool / Feature | Purpose |
|---|---|
| Microsoft Excel | Data analysis |
| SUM, AVERAGE | Numerical calculations |
| IF | Conditional analysis |
| XLOOKUP | Data lookup |
| Pivot Tables | Data summarization |
| Pivot Charts | Data visualization |
| Data Cleaning | Handling inconsistent and missing data |
| Conditional Formatting | Highlighting important information |
